Sobre CapyFront

CapyFront fue creado para desarrolladores que valoran la claridad, la velocidad y el control total.

Principios

  • Sin dependencias — HTML, CSS y JS nativos. Sin npm, sin bundler, sin build step.
  • Modular — cada componente, página y acción vive en su propio archivo.
  • Automatizado — capy-new genera y registra todo automáticamente.

Features demostradas en esta app

  • Web Components con Shadow DOM
  • Router hash-based con parámetros (#product/:id)
  • Título de pestaña por ruta ({ load, title })
  • Store global reactivo con subscribe
  • Persistencia con localStorage y sessionStorage
  • Comunicación hijo→padre con emit()
  • Event delegation sobre Shadow DOM
  • {{#each}} y re-render con el.render()
  • Auth token con setAuthToken()
  • Capa de modelos (models/response/, models/request/)
  • onDisconnect para limpiar suscripciones y timers
