Sobre CapyFront

Un micro-framework para desarrolladores que valoran la claridad, la velocidad y el control total.

Principios

  • Sin dependencias — HTML, CSS y JS nativos. Sin npm, sin bundler, sin build step.
  • Modular — cada componente, página y acción vive en su propio archivo.
  • Automatizado — capy-new genera y registra todo automáticamente.
  • Portátil — funciona en cualquier hosting estático: GitHub Pages, Netlify, etc.

Cómo funciona

  • El router lee el hash de la URL (#ruta) y monta el componente de página correspondiente.
  • Cada componente usa Shadow DOM — estilos y markup encapsulados, sin colisiones.
  • El store global notifica a los suscriptores en cada cambio de estado.
